# ADR-010: RAG Integration v2 — Local Per-Directory Index

**Date:** 2026-11-08  
**Status:** Accepted (Deferred to v2)

## Context

Retrieval-Augmented Generation for codebase-aware answers.

## Decision

**v2 only** — Local vector index in `.shai/rag/` per project.
- `rag_ingest`: Index files (Level 2 — reads all files)
- `rag_query`: Semantic search (Level 1)
- Embedding via Ollama (`nomic-embed-text`) or local ONNX
- Index: ChromaDB embedded or Qdrant embedded

## Rationale

- Per-directory matches history scope (ADR-004)
- Local-only — no data leaves machine
- Can use existing Ollama for embeddings
- Deferred to v2 — v1 focus on core loop + tools

## Consequences

- New dependencies: `chromadb`/`qdrant-client`, `onnxruntime`
- Background indexing on first `rag_query` or explicit `rag_ingest`
- Config in `[rag]` section
