# ADR-011: SSH Integration v2 — Key-Based Only

**Date:** 2026-11-08  
**Status:** Accepted (Deferred to v2)

## Context

Remote command execution via SSH.

## Decision

**v2 only** — Key-based auth only, uses `~/.ssh/config` hosts.
- `ssh_exec`: Run command on remote (Level 3–4, LLM-classified)
- `ssh_copy`: Copy files (Level 3)
- No password auth, no host key auto-accept

## Rationale

- Key-based is standard secure practice
- Leverages existing `~/.ssh/config` — no duplicate config
- Deferred to v2 — v1 is local-only

## Consequences

- Dependency: `ssh2`, `tokio-ssh2`
- Host config in `[ssh]` section
- Risk classification via LLM (like `shell`)
